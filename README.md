# Fortune in a Pot

Entry for the make.fun competition [Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9).

`main.py` writes a single line — one kind, funny fortune for the
houseplant on the windowsill, 117 characters — to `/output/entry.txt`:

> You will lean toward the sun, outgrow your little pot, and finally get watered before you have to drop a leaf to ask.

The fortune is built from three beats (sun-leaning specificity, a warm
growth prediction, and a gentle joke at the keeper's forgetfulness) —
see the docstring in `main.py`. Run it with `python3 main.py`; set
`OUTPUT_DIR` to redirect the output for local testing.
